# 車機Play（com.cheji.play）

[繁體中文（台灣）](README.md) · [简体中文](README.zh-CN.md) · [English](README.en.md) · [日本語](README.ja.md) · [한국어](README.ko.md)

**同じ内容をウェブページで（スクリーンショットと手順を含む）：** <https://jin850921.github.io/chejiplay>

カーナビ画面の CarPlay／Android Auto 入口 — カード形式のダウンロード＆起動アプリです。DiPlay／DiAuto の最新版 APK を取得し、インストール後はカードをタップするだけで始動します。

[APK をダウンロード](https://github.com/jin850921/chejiplay/releases/download/v1.0/chejiplay-1.0.apk) ／ [GitHub のソース](https://github.com/jin850921/chejiplay) ／ [Releases](https://github.com/jin850921/chejiplay/releases)

root 不要、ADB 不要、スマホ側のアプリも不要。

APK はスマホではなくカーナビにインストールします。Java と framework API のみで構成し、Gradle、AndroidX、外部依存は一切ありません。インストールの可否や自動起動に登録できるかは、カーナビ側のシステム次第です。

**DiPlay と DiAuto は BYD 車のカーナビを主力としているため、他の車種では動作を保証しません。**

## カーナビにインストール

インストール先はカーナビ側です（iPhone や Android スマホではありません）。アプリ自体はオフラインでも使え、ネットワークが必要なのは更新確認と APK ダウンロードだけです。

1. 停車中に `chejiplay-1.0.apk` をダウンロードし、カーナビ自身のインストーラーで開きます。他の出所からの APK インストールを許可してください。
2. 「車機Play」を開くと、2 列のカードがカーナビ上のインストール状況を直接読み取ります。
3. 「車機Play」を起動時自動スタートのリストに登録すると、画面が点くたびにこのページが開きます。名称と場所は車載メーカーによって異なります。
4. カードをタップすると CarPlay または Android Auto に入ります。未インストールの場合は先にダウンロードし、ダウンロード中に長押しすればキャンセルできます。

ADB も root も不要です。DiPlay／DiAuto の APK を改変したり再パッケージしたりすることはなく、ダウンロード先は常に相手 Releases の公式アセットです。

## このアプリの役割

- ホームは 2 列のカード：上段に DiPlay（CarPlay）と DiAuto（Android Auto）、下段に Google Maps と、自分で選んだ 1〜2 個のアプリ。
- GitHub Releases を 1 日 1 回チェックしますが、リマインダー画面は出しません。新版があっても ⋮ メニューに赤い点灯が出るだけです。
- カード自体が操作です。未インストールならダウンロード、済みなら起動。長押しでキャンセル／差し替え／削除が出ます。
- ダウンロードした APK はカーナビ自身のインストーラーに引き渡し、中継サービスは一切使いません。
- ⋮ メニューは全 9 行：バージョン確認、3 つのダウンロード元、まとめてダウンロード、本アプリの更新、ショートカット設定、説明ページ、言語、テーマ。

## ショートカットとアイコン

- 下段のアイコンはすべてカーナビ上のアプリ自身のアイコンを使います。取得できれば色を乗せず全面表示にします。
- 取得できない場合だけ内蔵の既定図に戻ります。Google Maps は公式カラーのピン、空枠は「＋」です。
- インストール、削除、あるいは相手のアプリがアイコンを変えた場合、本アプリに戻る、またはパッケージのブロードキャストで再描画され、再起動は不要です。
- Google Maps ショートカットは起動のみ担当し、ダウンロードも更新確認もしません。Maps の更新はカーナビ上の Google Play に任せます。
- 手動枠は最大 2 つ：タップで選択または起動、長押しで差し替えまたはホーム画面から削除。

## 起動アニメーション

コールドスタート時は全長 1.5 秒のレイヤーが画面を覆います。テーマや言語の切り替えは再描画のみで、再生されません。

- 車の線画が左から入り、ロゴバッジが跳ねて定位置に、続いてタイトルと案内がフェードインします。
- 進捗バーは起動進捗を表示し、アニメーションに合わせて 0 から 90% まで進みます。最後の 10% は最初のレイアウトが実際に戻ったときだけ解放されます。
- レイアウトが終わると全体がフェードアウトします。保険の上限は 3 秒で、そちらを通った場合は実際に到達した値のままになり、読み終えたふりはしません。

## 表示言語

繁体字中国語、簡体字中国語、English、日本語、한국어、およびカーナビのロケールに従う「自動」を選べます。

- 選択直後に画面を再描画します。再インストールは不要で、設定も消えません。
- アプリ名、ブランド名、カーナビ上のアプリ名は意図的に翻訳しません。翻訳するとそのアプリを探せなくなります。
- 訳文はメンテナーが作成し、母語話者による校閲は受けていません。文を変更するには `L.java` の 1 行を直してください。

## 更新と署名

バージョンは常に `version_name(version_code)` の形式で表記します。例：1.0(1)。

- 毎日チェックするのはこのリポジトリの Releases です。tag は `v1.0`、アセット名は `chejiplay-1.0.apk`。
- チェックはバージョン番号の比較だけで、自動インストールはしません。ダウンロードも更新も ⋮ メニューの各行から手動で実行します。
- 新版への入れ替えは同じ署名鍵でなければカーナビがアップグレードを拒否します。鍵とパスワードファイルはリポジトリに含めません。
- 「DiPlay＋DiAuto をまとめてダウンロード」は 2 件のみで本アプリを含みません。車機Play の更新は別の行です。

## 実車での未検証

開発中に実車にもシミュレータにも接続していません。検証はすべて静的です。署名済み APK から badging、リソース ID、DEX の文字列プールとバイトコードを取り出して比較し、翻訳カバレッジ確認と 1280×720 の比較図も生成しています。

- 実際の見た目、カーナビがインストール権限を出すか、各言語で行折り返し後の文字列長は、実機でしか確認できません。
- カーナビが Google Maps 自身のアイコンを返すかどうか（返さない場合、そのカードは内蔵のピンになり、空白にはなりません）。
- トーストがカーナビのフォントで何文字入るか。長さは 14sp で見積もり、既に入ることが分かっている幅以内に各文を抑えています。

問題が起きたときは車載メーカー、DiLink／Android のバージョン、APK のバージョン、発生時刻を添えて issue を開いてください。

[問題を報告](https://github.com/jin850921/chejiplay/issues/new/choose)
