車機螢幕上的
CarPlay／Android Auto 入口

一個卡片式的下載與啟動入口：抓 DiPlay／DiAuto 的最新版 APK，裝好之後點一下就進入。

下載 APK ↓ 安裝步驟 GitHub 原始碼

不需要 root、不需要 ADB、不需要手機端 App。

APK 裝在車機上，不是裝在手機。純 Java／framework 專案，沒有 Gradle、沒有 AndroidX、沒有任何第三方相依。能不能安裝、能不能加入開機自啟動，都由車機系統決定。

DiPlay 與 DiAuto 以 BYD 車機為主力，其他品牌不保證可用。

畫面

每張都是 1280×720 的 1:1 對照圖，依 repo 裡 `res/` 的實際色值與版面渲出來，不是設計稿；尚未裝上車機驗證。

01

裝在車機上

裝在車機，不是裝在 iPhone 或 Android 手機。整個 App 離線也能用，只有檢查更新與下載 APK 需要網路。

  1. 停車時下載 chejiplay-1.0.apk，用車機自己的安裝程式開啟；車機要允許安裝其他來源的 APK。
  2. 打開「車機Play」，主畫面兩排卡片會直接讀車機上的安裝狀態。
  3. 把「車機Play」加入車機的開機自啟動清單，之後每次開車機螢幕就自動打開這裡。清單的名稱與位置依車機品牌不同。
  4. 點卡片就進入 CarPlay 或 Android Auto；那款還沒裝的話會先下載，下載中長按卡片可以取消。

本 App 不需要 ADB、不需要 root，也不修改、不重新打包 DiPlay／DiAuto 的 APK——下載位置永遠是對方 Releases 的官方資產。

02

這支 App 做什麼

  • 主畫面兩排卡片：上排 DiPlay（CarPlay）與 DiAuto（Android Auto），下排是 Google Maps 快捷鈕與你自己挑的 1–2 個 App。
  • 每天檢查一次 GitHub Releases 的最新版，不跳任何提醒畫面；有新版只在右上角 ⋮ 亮起紅點。
  • 卡片本身就是動作：沒裝就下載，已裝就開啟；長按才出現取消下載／換 App／移除。
  • 下載好的 APK 交給車機自己的安裝程式，不經過任何中間服務。
  • 右上角 ⋮ 一共 9 列：查版號、三個下載來源、批次下載、本 App 更新、快捷鈕設定、說明頁、語言、主題。
03

快捷鈕與圖示

  • 下排那一列的圖一律取車機上那套 App 自己的圖示，查得到就滿版顯示、不壓色。
  • 查不到才退回內建預設圖：Google Maps 是官方配色的圖釘，還沒放 App 的欄位是「＋」。
  • 裝好、移除，或那套 App 換了圖示，回到本 App 或收到套件廣播就重畫，不用重開程式。
  • Google Maps 快捷鈕只負責開啟，永不下載、永不檢查更新——Maps 的更新交給車機上的 Google Play。
  • 手動欄位最多兩欄：點一下是選 App 或開啟 App，長按換一個或從主畫面移除。
04

載入動畫

冷開機進主畫面時先蓋一層載入動畫，總長 1.5 秒；換主題、換語言只重繪畫面，不會重播。

  • 車身線稿從畫面左側駛入，logo 徽章彈到位，標題與提示接著淡入。
  • 進度條顯示啟動進度：跟著動畫從 0 走到 90%，最後 10% 要等首輪排版真的回來才解鎖。
  • 排版一完成就整層淡出；保險上限 3 秒，走這條時進度留在實際到達的數值，不會假裝讀完。
05

介面語言

介面有繁體中文、簡體中文、English、日本語、한국어，外加「自動」照車機語系。

  • 選完立刻重繪畫面，不用重裝、不會掉設定。
  • App 名稱、品牌名與車機上那套 App 的名字刻意不翻——翻了就找不到那支 App。
  • 譯文由專案維護者撰寫，沒有母語人士校過；要改任何一句，改 `L.java` 那一列就好。
06

更新與簽章

版號一律寫成 `version_name(version_code)`，例如 1.0(1)。

  • 每日檢查讀的是這個 repo 的 Releases：tag v1.0、資產檔名 chejiplay-1.0.apk。
  • 檢查只查版號，不會自己安裝；下載與更新一律從 ⋮ 選單裡那幾列手動執行。
  • 換裝新版必須用同一支簽名金鑰，否則車機會拒絕升級安裝；金鑰與密碼檔不放在 repo 裡。
  • 「DiPlay＋DiAuto 兩個都下載」是批次列，不含本 App；更新車機Play 是選單裡單獨那列。
07

尚未裝上車機驗證

開發過程沒有接過實車車機，也沒有模擬器。所有驗證都是靜態的：從簽好的 APK 挖出 badging、資源 ID、DEX 字串池與位元碼比對，加上翻譯覆蓋率檢查與 1280×720 對照圖。

  • 實際外觀、車機有沒有給安裝權、各語言換行之後的文字長度，都要裝上車機才知道。
  • 車機到底有沒有回報 Google Maps 自己的圖示（查不到時那一格是內建圖釘，不會變空白）。
  • 訊息（Toast）在車機字體下放得下幾個字——句子長度按 14sp 估算，每句都刻意留在已知放得下的寬度以內。

遇到問題請附車機品牌、DiLink／Android 版本、APK 版號與發生時間，開一個 issue。
