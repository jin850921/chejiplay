차량 화면의
CarPlay／Android Auto 입구

카드 형태의 다운로드·실행 입구입니다. DiPlay／DiAuto의 최신 APK를 받고, 설치 후에는 카드를 탭하면 바로 들어갑니다.

APK 다운로드 ↓ 설치 방법 GitHub 소스

root 불필요, ADB 불필요, 폰 앱도 불필요.

APK는 폰이 아니라 차량용 헤드유닛에 설치합니다. Java와 framework API만으로 만든 프로젝트로 Gradle, AndroidX, 외부 의존성이 전혀 없습니다. 설치 허용과 부팅 시 자동 시작 등록 여부는 헤드유닛 시스템이 결정합니다.

DiPlay와 DiAuto는 BYD 차량용 헤드유닛을 기준으로 하므로 다른 브랜드는 동작을 보장하지 않습니다.

화면

모두 1280×720을 1:1로 렌더한 비교 그림입니다. 저장소의 `res/`에 있는 실제 색과 배치를 그대로 사용했으며, 디자인 시안이 아닙니다. 실차 검증은 아직 없습니다.

01

차량에 설치

iPhone이나 Android 폰이 아니라 차량용 헤드유닛에 설치합니다. 앱 자체는 오프라인에서도 동작하며, 네트워크가 필요한 것은 업데이트 확인과 APK 다운로드뿐입니다.

  1. 정차 중에 chejiplay-1.0.apk를 내려받아 헤드유닛의 설치 앱으로 여십시오. 다른 출처의 APK 설치가 허용되어 있어야 합니다.
  2. 「車機Play」를 열면 두 줄의 카드가 헤드유닛의 설치 상태를 직접 읽어옵니다.
  3. 「車機Play」를 부팅 자동 시작 목록에 넣으면 화면이 켜질 때마다 이 페이지가 열립니다. 목록의 이름과 위치는 차량 브랜드마다 다릅니다.
  4. 카드를 탭하면 CarPlay 또는 Android Auto로 들어갑니다. 아직 설치되지 않았다면 먼저 다운로드하며, 다운로드 중에 길게 누르면 취소할 수 있습니다.

ADB와 root가 필요 없습니다. DiPlay／DiAuto의 APK를 수정하거나 재포장하지 않으며, 다운로드 위치는 항상 해당 Releases의 공식 자산입니다.

02

이 앱이 하는 일

  • 홈은 두 줄 카드입니다. 위쪽은 DiPlay(CarPlay)와 DiAuto(Android Auto), 아래쪽은 Google Maps와 직접 고른 1–2개 앱.
  • GitHub Releases를 하루 한 번 확인하지만 알림 화면은 띄우지 않습니다. 새 버전이 있으면 오른쪽 위 ⋮에만 빨간 점이 켜집니다.
  • 카드 자체가 동작입니다. 설치 전이면 다운로드, 설치 후에는 실행. 길게 눌러야 취소／교체／제거가 나타납니다.
  • 다운로드가 끝난 APK는 헤드유닛의 설치 앱에 넘기고, 중간 서비스는 거치지 않습니다.
  • 오른쪽 위 ⋮는 모두 9개 행입니다. 버전 확인, 세 개의 다운로드 출처, 묶음 다운로드, 이 앱 업데이트, 단축 버튼 설정, 설명 페이지, 언어, 테마.
03

단축 버튼과 아이콘

  • 아래쪽 줄의 그림은 전부 헤드유닛에 설치된 앱 자신의 아이콘을 사용합니다. 찾으면 색을 덮지 않고 가득 채워 표시합니다.
  • 찾지 못할 때만 기본 내장 그림으로 돌아갑니다. Google Maps는 공식 배색 핀, 비어 있는 칸은 「＋」입니다.
  • 설치되거나 삭제되거나 해당 앱의 아이콘이 바뀌면, 이 앱으로 돌아오거나 패키지 브로드캐스트를 받는 순간 다시 그리므로 프로그램을 다시 켤 필요가 없습니다.
  • Google Maps 단축 버튼은 실행만 담당합니다. 다운로드도 업데이트 확인도 하지 않으며, Maps 관리는 헤드유닛의 Google Play에 맡깁니다.
  • 수동 칸은 최대 두 개입니다. 탭하면 선택 또는 실행, 길게 누르면 교체 또는 홈 화면에서 제거.
04

로딩 애니메이션

콜드 스타트로 홈에 들어올 때 1.5초 동안 로딩 레이어가 화면을 덮습니다. 테마나 언어를 바꾸면 화면만 다시 그리며 재생하지 않습니다.

  • 차량 라인아트 화면 왼쪽에서 들어오고, 로고 배지가 튀어 제자리에 앉은 뒤 제목과 안내가 페이드인합니다.
  • 진행 표시줄은 시작 진행률을 보여 줍니다. 애니메이션과 함께 0에서 90%까지 가고, 마지막 10%는 첫 레이아웃이 실제로 돌아와야 열립니다.
  • 레이아웃이 끝나면 레이어 전체가 페이드아웃합니다. 안전 상한은 3초이며 그 경로로 끝나면 실제로 도달한 값 그대로 두고 다 읽은 척하지 않습니다.
05

인터페이스 언어

번체 중국어, 간체 중국어, English, 日本語, 한국어와 헤드유닛 언어를 따르는 「자동」을 고를 수 있습니다.

  • 고르면 즉시 화면을 다시 그립니다. 재설치도 없고 설정도 사라지지 않습니다.
  • 앱 이름, 브랜드 이름, 헤드유닛에 설치된 앱의 이름은 일부러 번역하지 않습니다. 번역하면 그 앱을 찾을 수 없게 됩니다.
  • 번역문은 유지보수자가 작성했으며 원어민 감수를 거치지 않았습니다. 문장을 고치려면 `L.java`의 해당 행을 수정하면 됩니다.
06

업데이트와 서명

버전은 항상 `version_name(version_code)` 형식으로 표시합니다. 예: 1.0(1).

  • 매일 확인하는 곳은 이 저장소의 Releases입니다. tag는 v1.0, 자산 이름은 chejiplay-1.0.apk.
  • 확인은 버전 번호만 비교하고 스스로 설치하지 않습니다. 다운로드와 업데이트는 모두 ⋮ 메뉴의 행에서 직접 실행합니다.
  • 새 버전으로 갈아타려면 같은 서명 키를 써야 합니다. 다르면 헤드유닛이 업그레이드 설치를 거부합니다. 키와 비밀번호 파일은 저장소에 두지 않습니다.
  • 「DiPlay＋DiAuto 모두 다운로드」는 묶음 행이며 이 앱을 포함하지 않습니다. 車機Play 업데이트는 별도의 행입니다.
07

실차 검증은 아직

개발 중에 실제 차량이나 에뮬레이터에 연결해 보지 않았습니다. 검증은 모두 정적입니다. 서명된 APK에서 badging, 리소스 ID, DEX 문자열 풀과 바이트코드를 뽑아 비교하고, 번역 커버리지 검사와 1280×720 비교 그림을 함께 확인했습니다.

  • 실제 모습, 헤드유닛이 설치 권한을 주는지, 언어별로 줄바꿈 뒤 문자열 길이는 차량에 설치해 봐야 알 수 있습니다.
  • 헤드유닛이 Google Maps 자신의 아이콘을 알려주는지 (알려주지 않으면 그 카드는 내장 핀으로 표시되고 빈칸이 되지는 않습니다).
  • Toast 문장이 헤드유닛 글꼴에서 몇 글자까지 들어가는지. 길이는 14sp로 계산해 이미 들어가는 폭이 확인된 너비 안에 각 문장을 맞춰 두었습니다.

문제가 생기면 헤드유닛 브랜드, DiLink／Android 버전, APK 버전, 발생 시각을 적어 issue를 열어 주십시오.
